# Profile motion assets

The assets in this directory are deterministic exports generated by
`render.py`.

- The profile animation uses the existing badge blue (`#3b82f6`) translated to
  GitHub's light and dark contrast colors.
- The Versed insertion mark preserves the vector geometry documented in
  `versed/app/components/logo.tsx`.
- The Versed light and dark palettes come from `versed/app/globals.css`:
  parchment, iron-gall ink, and antique brass.
- Exact labels and dimensions are composed by the renderer rather than an
  image model.
- PNG counterparts are static fallbacks for reduced-motion visitors.

Run the renderer with the workspace Python runtime and Pillow:

```bash
python3 assets/profile-motion/render.py
```
